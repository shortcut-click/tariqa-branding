# Tariqa Pro · Branding, naming et création de marque

Cours interactif du Collectif Tariqa Pro. Une fois installé, Claude devient ton
formateur branding : il t'enseigne les fondamentaux, applique les frameworks à
ton projet et produit avec toi ton dossier de marque complet.

## Ce que le cours couvre

Trois parcours, choisis automatiquement selon ta situation :

- **APPRENTISSAGE** : comprendre le branding sans jargon inutile. Positionnement,
  distinctivité, naming, architecture de marque, mesure, avec les débats de la
  discipline plutôt qu'une seule école présentée comme vérité.
- **EXÉCUTION** : interview structurée en 7 phases qui aboutit à ton dossier de
  marque autoportant, utilisable tel quel avec un designer, un rédacteur, une
  agence ou dans un projet Claude.
- **MINIMUM VIABLE BRAND** : pour une boutique e-commerce en phase de test
  (produit pas encore validé par les ventes). Assez de marque pour être crédible
  et conforme, pas plus. La marque complète vient après la validation.

Modules spécialisés inclus : branding islamique, luxe et premium, rebranding,
marque personnelle (avec le cas de la non-exposition du visage).

## Installation

Prérequis : [Claude Code](https://claude.com/claude-code) (terminal ou
application de bureau).

Dans Claude Code, lance ces deux commandes :

```
/plugin marketplace add shortcut-click/tariqa-branding
```

```
/plugin install tariqa-branding@tariqa-branding
```

C'est tout. Redémarre la session si le cours ne se déclenche pas immédiatement.

## Utilisation

Parle simplement de ton sujet : « je cherche un nom pour ma boutique »,
« aide-moi à me positionner », « c'est quoi un bon branding », « je lance ma
marque ». Le cours se déclenche tout seul et t'oriente vers le bon parcours.

## Mise à jour

```
/plugin marketplace update tariqa-branding
```

## Questions

Pour toute question sur le contenu du cours ou ton cas particulier, vois
